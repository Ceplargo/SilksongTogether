# Changes in this copy of SSMP (branch `coop`)

This is a modified copy of [SSMP](https://github.com/Extremelyd1/SSMP), based on its `world-sync` branch
(commit `b62a2f4`), changed for a group that plays one shared Silksong save. SSMP is licensed under the LGPL-2.1, and
so is this copy (see `LICENSE`). Every change below was made between 25 and 29 October 2026 and is its own commit on `coop`
(`git log world-sync..coop --stat`).
